# Tripway

Website fictício de uma agência de turismo especializada em viagens e experiências de aventura.

O projeto foi desenvolvido como **CP1 da disciplina de Front-End do curso de Análise e Desenvolvimento de Sistemas (ADS) da FIAP**, com foco na prática de HTML, Git e GitHub.

## 🏔️ Sobre o projeto

A **Tripway** é uma agência fictícia de turismo voltada para pessoas que buscam experiências de aventura e destinos fora do caminho tradicional.

## 🎯 Objetivo

O principal objetivo da CP1 é aplicar e praticar conceitos de desenvolvimento Front-End e versionamento de código, como:

- Estruturação de páginas com HTML
- Uso de HTML semântico
- Organização de arquivos e pastas
- Criação de formulários
- Versionamento de código com Git
- Uso do GitHub
- Criação e gerenciamento de branches
- Desenvolvimento colaborativo
- Criação de Pull Requests
- Realização de merges

## 🛠️ Tecnologias

- HTML5
- Git
- GitHub
- Visual Studio Code

## 📁 Estrutura do projeto

```text
tripway/
├── index.html
├── pages/
├── images/
└── README.md
```

- `index.html`: página principal do projeto.
- `pages/`: pasta que contém as demais páginas do site.
- `images/`: pasta destinada às imagens utilizadas no projeto.
- `README.md`: documentação do projeto.

O projeto apresenta seções e recursos como:
