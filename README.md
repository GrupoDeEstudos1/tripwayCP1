# Tripway

Website fictício de uma agência de turismo especializada em viagens e experiências de aventura.

O projeto foi desenvolvido como CP1 da disciplina FrontEnd do Curso de ADS na FIAP com foco na prática de HTML, Git e GitHub.

---

## 🏔️ Sobre o projeto

A Tripway é uma agência fictícia voltada para pessoas que buscam experiências únicas.

## 🎯 Objetivo

O objetivo principal da CP1 é aplicar conceitos Front-end:

- Estruturação de páginas com HTML
- HTML semântico
- Organização de arquivos e pastas
- Criação de formulários
- Versionamento de código com Git
- Uso de GitHub
- Criação e gerenciamento de branches
- Desenvolvimento colaborativo
- Pull Requests e merges

## 🛠️ Tecnologias

- HTML5
- Git
- GitHub
- Visual Studio Code

## 📁 Estrutura

```text
tripway/
├── index.html
├── pages/
├── images/
└── README.md


### Descrição das principais pastas

- `index.html`: página principal do projeto.
- `pages/`: outras páginas do projeto.
- `images/`: página de imagens.
- `README.md`: documentação do projeto.

## ✨ Funcionalidades

O projeto apresenta funcionalidades e seções como:

- Rodapé
